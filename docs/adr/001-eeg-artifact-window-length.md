# ADR-001: EEGアーチファクト判定のWelch窓長を4秒にする

## Status

Accepted (2026-07-31)

## Context

振幅ベースのアーチファクト除去（`lib/sensors/eeg/artifact.py`）は、HSIが検出できない
眼球運動・筋電・電極ずれを落とすために導入した。判定粒度はPSDのWelch窓に揃えており、
当初は 2048サンプル（8秒 @256Hz）だった。

しかし2026-07-31セッション（16.6分）で除外率が14.7%に達し、0-3分セグメントが
「除外率30%超」として noisy 判定された。瞑想セッションは15分程度のことが多く、
この規模の除外は解釈に使えるデータを実質的に失わせる。

窓は「1点でも閾値を超えたら丸ごと落ちる」ため、窓長がそのまま巻き添え損失になる。
同セッションの実測:

| 項目 | 値 |
|------|---:|
| 実際に汚染されていた時間（どれか1chが閾値超えの秒） | 85秒 / 996秒 (8.5%) |
| 8秒窓が除外していたチャネル時間 | 146秒相当 |
| 1秒粒度で除外した場合 | 39秒相当 |

窓長別の除外率:

| 窓長 | TP9 | AF7 | AF8 | TP10 | 平均 |
|-----:|----:|----:|----:|-----:|-----:|
| 1秒 | 1.1 | 6.9 | 7.3 | 4.5 | 5.0% |
| 2秒 | 2.0 | 8.2 | 8.8 | 7.2 | 6.6% |
| 4秒 | 4.0 | 10.8 | 11.2 | 11.2 | 9.3% |
| 8秒 | 7.3 | 16.1 | 16.1 | 19.4 | 14.7% |

汚染の実体は、delta帯（1-4Hz）が63-73%を占め gamma がむしろ減る低周波トランジェント
（尖度23-33、最大p2p 1175µV @TP10）で、8秒窓のうち逸脱サンプルは6-11%しかなかった。
筋電ではなく、嚥下・姿勢微動・電極ずれ相当の1秒未満のスパイクである。

代替案として**スライディング窓（hop 1秒）**を検証したが、有効率はほぼ変わらなかった
（AF7で85.5% → 86.0%）。汚染イベントが10-20秒間隔で発生する区間では、
どこに8秒窓を置いても必ず1発当たる。窓をずらすのではなく短くする必要がある。

## Decision

**`ARTIFACT_WINDOW_SAMPLES` を 2048（8秒）から 1024（4秒）に短縮する。**

閾値ルール（絶対150µV / チャネル別p2p中央値の4倍 / 下限50µV）は変更しない。
1175µVのような明確な非EEGを捕捉できており、緩めると2026-07-28で起きた
「アーチファクト区間が最高パフォーマンス区間として提示される」問題に戻る。

窓長は `create_statistical_dataframe(window_samples=...)` と
`generate_report.py --artifact-window-samples` で上書きできるようにし、
設定ファイルには出さない。値の根拠がコードから剥がれるのを避けるため。

## Consequences

2026-07-31セッションで再生成した実測:

- 除外率 14.7% → **9.3%**（実際の汚染時間8.5%にほぼ一致）。
  チャネル別は TP9 7.3→4.0 / AF7 16.1→10.8 / AF8 16.1→11.2 / TP10 19.4→11.2%。
- セグメント別の除外率は 30.7→21.1 / 36.4→24.4 / 0→0 / 0→0 / 4.6→3.3%。
  ただし先頭2セグメントは `PEAK_MAX_EXCLUDED_RATIO`（20%）をまだ超えており
  noisy 判定は残る。汚染が集中している区間なので、これは妥当な結果と判断する。
- セグメント別IAFが0.25Hz刻みに量子化され（8.50/8.62/8.62/8.50/8.75 →
  8.50/8.50/8.75/8.75/8.75）、周波数安定性スコアが 75.7 → 68.3 に下がった。
  実態の変化ではなくビン幅の副作用。気になるならセグメント別IAFを
  Peak方式からCoG方式（補間値なのでビン幅に強い）に変える余地がある。
- セグメント別ITFが全区間5.00Hzに張り付いた。ただし変更前も 6.38/5.00/7.00/5.00/5.12 と
  探索範囲（5.0-7.0Hz）の端に張り付いており、もともと信頼できていない指標。
  窓長変更による劣化ではなく、既存の問題が見えやすくなっただけ。別途対応が必要。
- セグメント別指標の周波数分解能が 0.125Hz → 0.25Hz に落ちる。
  影響は `statistical_dataframe` 経由の時系列テーブル（θ/α、Fmθ、SE、IAF列）に限られる。
  レポート見出しの IAF/PAF/PSD/スペクトログラムは `generate_report.py` が
  `calculate_psd(raw)`（n_fft=2048）で別途計算しているため解像度は落ちない。
- `SEGMENT_MIN_VALID_RATIO` / `PEAK_MAX_EXCLUDED_RATIO` は据え置き。
  除外率の分母が実態に近づけば、現行の閾値のままで意図通りに働く。

## 未解決の課題

`calculate_psd(raw)` 経由の全セッションPSD（見出しのIAF・PSDピーク表・
スペクトログラム・Spectral Entropy）は**アーチファクト除去を通っていない**。
2026-07-31では2.8Hz/3.5Hzのdeltaピークが13.1/11.2 dBでαを上回っていたが、
これが低覚醒の実態なのか3-6分の汚染区間の寄与なのかを、現状は分離できていない。
別途対応が必要。
